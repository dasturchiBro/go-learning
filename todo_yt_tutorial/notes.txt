# MAIN SETUP
create folders
set up main.go and go mod init
install: Gin, Pgx, JWT 
install go-migrate: go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest
install bcrypt: go get -u golang.org/x/crypto/bcrypt
install godotenv: go get -u github.com/joho/godotenv
install air: go install github.com/air-verse/air@latest

# AIR
to initialize AIR, you have to run: air init
change cmd = "go build -o ./tmp/main.exe ./cmd/api" in .air.toml file


# Working with DATABASE
you can get access to the postgres CLI by running: psql -U postgres
to see databases: \l
to create a new database: CREATE DATABASE todo_api_yt;
to connect to a database: \c database_name
to see tables: \dt

# SET UP MIGRATIONS
create a migrations folder in the root directory    
create an initial migration file using the command:
    migrate create -ext sql -dir ./migrations -seq create_todos_table
set up the todos table in the migration file with fields: id, title, completed, created_at, updated_at
create a scripts folder in the root directory with a migrate.ps1 file to run migrations

# RUN MIGRATIONS
run the migrations using the powershell script:
    ./scripts/migrate.ps1 up
